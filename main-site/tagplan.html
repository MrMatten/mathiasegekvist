Dag 1, 2 og 3

PrincipTaget deles i sektioner. En sektion åbnes og lukkes med plader samme dag. Hele taget står aldrig åbent.

Rul pr. sektion

  1. Sten af
  2. Sten ned og renset
  3. Gammelt undertag af
  4. Plader op
  5. Presenning på hvis dagen slutter

Etape 2

Afdækning ved fyraften

  1. Presenning over hele den åbne flade
  2. Fastgøres fra kippen og ned
  3. Lægter over presenningen som klemlister
  4. Fald hele vejen, ingen vandlommer
  5. Kip og samlinger mellem plader afdækkes særskilt
  6. Efterses efter regn og blæst
Åbne punkterKippen er ikke oppe før etape 4. Samlinger mellem plader er ikke tætte før tagpappen er på.
